# Выпуск плагина

1. Обновите версию в исходном репозитории плагина. Для совместимого исправления увеличьте patch. Проверьте поведение в BB, запустите доступные тесты, сохраните результат в коммите исходного репозитория.
2. В этом репозитории запустите `python3 scripts/prepare-release.py <id>`. Скрипт берёт сохранённый снимок Git, собирает его отдельно, запускает проверки и готовит каталог `plugins/<id>`. Для другого расположения исходников есть `--source-dir`.
3. Проверьте diff и данные в снимке. Закоммитьте проверенный снимок и создайте новый неизменяемый тег `<id>/v<version>`. Отправьте коммит и тег одной командой `git push --atomic origin main refs/tags/<id>/v<version>`.
4. Если прежний диапазон каталога включает новую версию, BB найдёт её по тегу. При изменении описания, снимков либо диапазона обновите PR в `get-bb/marketplace`. Для новой карточки подключите отдельный PR или добавьте её к открытому выпуску по согласованию с владельцем.
5. Сверьте тег и его коммит в GitHub, затем проверьте карточку и галерею. Запись появляется в BB Community после слияния PR командой BB. Для локального каталога используются абсолютные HTTPS-ссылки на снимки из проверенного коммита.

Для установки с обновлениями используйте один и тот же Git-репозиторий и подкаталог, которые указаны в карточке. BB требует удалить прежнюю локальную регистрацию перед заменой её источника. Перед переносом действующей установки проверьте и сохраните настройки и данные плагина.
