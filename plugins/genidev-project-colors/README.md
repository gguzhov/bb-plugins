# Цвета проектов bb

Откройте «…» у проекта в сайдбаре → Project settings. Палитра расположена сразу под названием проекта. Отдельного раздела в общих настройках нет. После Add project и добавления папки открывается выбор цвета нового проекта. Для каждого проекта доступны ровно десять вариантов:

1. Восемь готовых цветов.
2. Девятый кружок открывает собственную RGB-палитру при наведении, фокусе или нажатии. Наведение ничего не сохраняет. Нажмите или проведите курсором по спектру; точный цвет можно задать через R/G/B и кнопку «Применить».
3. Десятый вариант «Без цвета» снимает подчёркивание.

В сайдбаре цветом подчёркивается только название. Фон, точки и дополнительные кнопки отсутствуют. Переименование сохраняет выбранный цвет, поскольку настройка привязана к ID проекта. Двойной щелчок для переименования, сворачивание и пустые разделы сохраняют штатное поведение bb.

## Команды

```sh
bb genidev-project-colors list
bb genidev-project-colors set PROJECT_ID "#28A99C"
bb genidev-project-colors set PROJECT_ID none
```

## Разработка

```sh
npm ci
npm test
npm run typecheck
bb plugin build .
bb plugin reload genidev-project-colors
```

Используются публичный SDK, settingsSection и trusted content script. Разметка заголовка определяется по существующим DOM-маркерам bb; после обновления bb нужна проверка совместимости. Настройки хранятся в KV плагина на сервере bb.
