# Устройство Chat widget

Клиент BB собирает компактную карточку и полную панель из одних данных треда. Сервер плагина агрегирует источники, результаты и активность агентов. Позиция в журнале, записи и состояния архива хранятся в хранилище BB.

Блок Git получает рабочую папку треда и вызывает RPC на её хосте. Хост читает локальные изменения и до 20 коммитов текущей ветки. Git выполняет только операции чтения. Карточка и панель используют общий ответ, а переход «Посмотреть всё» использует цель вкладки BB.

`npm run build` собирает пакеты приложения, сервера и хоста. Активный BB загружает плагин из локального каталога командой `bb plugin reload thread-materials`.
