# Виджет чата

В карточке контекста BB четыре равные кнопки для Git, субагентов, результатов и источников. Виден один раскрытый раздел. Списки, сведения о субагентах, форма добавления и архив раскрываются в этой карточке. Кнопка «Ещё» показывает оставшиеся записи в том же разделе. Отдельные действия открывают файл, тред или штатную вкладку изменений Git.

Список субагентов сначала показывает три строки. Если BB ограничил размер ответа журнала, виджет уменьшает порцию событий. Если запрос ограничен даже для одного события, виджет показывает доступные данные и предупреждает о неполном списке.
