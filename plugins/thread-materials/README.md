# Материалы чата — плагин BB

Постоянный виджет справа вверху рядом с перепиской. Открытие правой панели с файлом, кодом или работой агента скрывает виджет; закрытие возвращает его. Отдельной кнопки плагина в заголовке нет.

## Виджет

Четыре равные кнопки открывают Git, субагентов, созданные материалы и вложения. У выбранной кнопки остаётся акцентный контур, пока раздел раскрыт. При наведении появляется подпись. «Посмотреть всё» открывает нужный раздел правой панели. Архив доступен там, в результатах.

Вложения поступают из сообщений пользователя, результаты — из созданных в треде материалов. У файла есть подсказка с названием. Git показывает хеши и темы трёх последних коммитов в карточке и до двадцати в панели.

## Разделы

- **Источники** — прикреплённые пользователем файлы и изображения, а также явно переданные ссылки на документы. Материалы из служебных сообщений других агентов сюда не попадают.
- **Результаты** — содержательные документы и артефакты, созданные этим чатом. Учитываются успешные события создания и явная регистрация. Сам факт чтения файла или упоминания ссылки не доказывает создание. Код, конфиги, внутренние инструкции, логи и проверочные файлы не показываются как документы.
- **Исполнители** — все встроенные субагенты (инструмент Agent/Task, включая фоновые) и дочерние треды bb за всю историю треда. Свёрнутая кнопка раздела показывает короткий счёт «N/M» (работают/всего; если никто не работает — «M») и красную точку при ошибках, расшифровка «N в работе · K завершили · E с ошибкой» — в подсказке; раскрытый раздел начинается строкой итога «В работе N · Завершили K · С ошибкой E». Возобновление агента через SendMessage не создаёт новую строку, а возвращает её в «работает». Слева значок состояния: синий вращающийся индикатор (работает, название мягко «дышит»; при reduced-motion — статичная точка), зелёная галочка (готово), красный знак (ошибка; под названием причина одной строкой цветом ошибки: «Кончился лимит модели · сброс в 7:00 по Москве», превышен контекст, остановка, сеть или первые 120 символов текста; полный текст без идентификаторов и путей — в подсказке; нет записи — «Причина не записана»), серый (остановлен). Работающие сверху, затем завершённые по времени окончания; завершённых больше пяти — «ещё N». Код тикета в начале названия (`R19`, `M1`, `BUH-06`) — моноширинная плашка. Под названием: модель · время работы · вызовы · токены (чего нет в данных — не показывается). Дочерний тред отмечен значком и открывается по нажатию; у субагента нажатие раскрывает его итог.

Откуда данные. История запусков — журнал событий треда (`threads.events.list`: `delegation`, `backgroundTask` с `familyId`, `client/turn/requested`). Он накапливается в хранилище плагина и дочитывается с последнего номера события, поэтому после перезагрузки bb список тот же. Дочерние треды — `threads.list({parentThreadId})`, включая архивные. Модель: фактическая, если её сообщает запуск (у дочернего треда — модель треда); иначе переданная параметром `model` (из подписи запуска «… · model sonnet»); иначе «как у ведущего (<модель ведущего на момент запуска>)» с приглушённым значком-подсказкой. Claude Code фактическую модель встроенного субагента наружу не отдаёт, поэтому у субагентов это модель, указанная при запуске. Имена моделей — словарь `MODEL_NAMES` в `agents.ts`; неизвестный id показывается как есть. Время, вызовы и токены — из `usage` фоновых запусков (вызовы суммируются по запускам, токены — максимум).

- **Строка git** (всегда первая, над «Результатами») — ветка и всё, чего ещё нет на GitHub для рабочей папки треда: зелёным `+N` добавленных строк, красным `−M` удалённых, приглушённо число файлов. Считается итоговое состояние папки (проиндексированное и нет, новые неотслеживаемые файлы) против точки ответвления от ветки на сервере (`@{upstream}`; без неё — от `origin/HEAD`; без неё — от `HEAD`), поэтому файл, изменённый и в неотправленном коммите, и на диске, учитывается один раз. Числа из `git diff --numstat`; строки новых файлов считаются как в git, двоичные и файлы больше 1 МБ — только как файлы, игнорируемые не считаются. Подсказка: «не закоммичено: +a −b · не отправлено: N коммитов». Чисто — «нет изменений», без git — «не git-репозиторий». Больше 2000 неотслеживаемых файлов — числа с «≥». Длинное имя ветки обрезается многоточием, числа остаются на месте. Нажатие открывает штатную вкладку Diff: если она уже открыта — выбирается через `experimental_useAppPanel().selectTab`, иначе вызывается собственная строка `bb--git` в карточке (SDK не даёт плагину открыть вкладку другого плагина). Строку «Changes» плагина `bb--git` в карточке контекста скрывает контент-скрипт `card-chrome.ts` — только пока наша строка посчитана (`[data-tm-git-ready]`); при ошибке или загрузке старая строка остаётся. Встроенный `bb git status` эти числа не даёт: для неотслеживаемых строк у него `null`, `lineStatsComplete: false`, неотправленные коммиты не учитываются.

## Установка из ZIP

Распакуйте архив в постоянную папку:

```sh
npm ci --include=dev
bb plugin build
bb plugin install .
bb settings experiment threadContextCard true
```

Требуется BB >=0.49 и SDK >=0.6.132. Эксперимент включается при первой установке. Положение и ширину карточки определяет BB. На узкой области чата используется штатное раскрытие контекста, на телефоне — вкладка «Материалы» правой панели. Закрепление: `bb settings ui set threadContextCard.pinned true`.

## Регистрация материалов

```sh
bb materials add --group result --title 'Финальный расчёт' --href '/absolute/path/calculation.xlsx'
bb materials add --group source --title 'Исходная заявка пользователя' --href '/absolute/path/input.xlsx'
```

`result` — созданный материал. `source` — только материал, предоставленный пользователем. Чат определяется контекстом CLI; при необходимости укажите `--thread thr_...`. Файлы, созданные через shell, могут не иметь отдельного события создания в BB; зарегистрируйте их явно. Ручное добавление доступно через плюс. Крестик снимает закрепление, не удаляя файл.

Один объект не дублируется в двух разделах: результат имеет приоритет. Идентичность локального файла учитывает компьютер, а вложения — исходный чат. Свежие материалы идут первыми.

## Границы

Сначала последние 100 сегментов истории, загрузка более ранних расширяет окно до 2000. Не более 1000 материалов за запрос. События исполнителей читаются страницами до 100. Если ответ BB превышает 8 МиБ, плагин уменьшает страницу и дочитывает историю от последнего сохранённого события. Если даже одно событие превышает лимит, раздел показывает доступные данные и предупреждение о неполном списке. Git считается на машине окружения (host entry `host.ts`) с таймаутом 10 с и вызывает только `git rev-parse`, `symbolic-ref`, `merge-base`, `rev-list`, `diff`, `ls-files`, `log` с `--no-optional-locks`; строка обновляется при открытии, по завершении хода и раз в 25 с, пока виджет виден. Данные обновляются раз в 10 секунд при видимом виджете. Автоматический сбор ограничен данными SDK; отсутствующие в истории документы не выдумываются. Экран работы встроенного агента показывает доступные сообщения, а не вымышленный отдельный чат.

Файлы открываются штатным просмотрщиком BB на компьютере исходного окружения. Данные хранятся в BB; внешние сайты не опрашиваются. Ядро BB и другие плагины не меняются.

```sh
npm run typecheck
npm test
bb plugin build
```

Удаление: Plugins → Материалы чата → Uninstall. Эксперимент штатной карточки отключается отдельно: `bb settings experiment threadContextCard false`.

## 0.5.0

Compact widget: three entries per section; Show all opens the full right panel. Sources use local image previews, no add button. Agent subtitles show recorded models; missing models remain explicit. Google Drive/Docs/Sheets/Slides icons come from official Google assets (assets/SOURCES.md).

The X control opens Archive / Delete from list / Cancel. These actions never delete disk files. Archived records can be restored via the Archive link. Deleted records remain suppressed during history refresh. Persistent per-thread indexing retains older attachments (up to 1000 items with visible limits).

Parent is hidden only in the compact card, remains in Info. The card uses rounded corners and a subtle theme-aware neutral gradient. Image previews validate thread ownership and PNG/JPEG/WebP signatures, up to 2 MiB after SDK read; remote URLs are not fetched.

Исполнителя можно удалить с подтверждением: дочерний тред останавливается и удаляется, завершённый субагент навсегда скрывается из виджета.
