# Notch Bar (genidev-touchbar)

Полоска у выреза камеры MacBook, которая показывает работу агентов bb: название проекта, круговую диаграмму «выполнено и осталось» по задачам плана и время работы агента.

Идея взята у плагина Touch Bar Agent Monitor из каталога bb. Тот рисует карточки тредов на физическом Touch Bar. На MacBook Pro 2021 года и новее Touch Bar нет, зато есть вырез с камерой, поэтому здесь полоска живёт вокруг выреза и видна поверх любого приложения.

## Что видно

- Свёрнутая полоска: робот, число проектов в работе, кольцо общей доли и счёт задач факт/план по всем тредам. Робот думает, спрашивает, радуется, расстраивается или спит по состоянию работы.
- Раскрытая панель (навести курсор): о чём думает робот, итог «9 тредов · 2 сейчас в работе · в них 27 задач», фильтры «Все», «Работают», «Пауза» и по строке на тред с планом. В строке значок проекта, текущая задача, время на неё и дорожка цветных блоков по задачам.
- Нажатие на строку раскрывает задачи по очередям с временем и исполнителем. Стрелка и кнопка «Открыть тред» открывают тред в bb.
- Когда тред закончил, упал или ждёт ответа, у выреза на несколько секунд появляется сообщение.
- Шестерёнка и правый щелчок дают настройки: обновить данные, сообщения, звук, выключить полоску.
- Когда тредов с планом нет, полоска скрыта.

Подробно о поведении: [features/notch-strip.md](features/notch-strip.md).

## Из чего состоит

- Плагин bb `genidev-touchbar` (в каталоге — Notch Bar) (TypeScript, без интерфейса в окне bb) считает сводку.
- Приложение `BBTouchbar.app` (Swift, AppKit и SwiftUI) рисует её. Исходники в `native/`.

Как части связаны: [ARCHITECTURE.md](ARCHITECTURE.md). Цвета и размеры: [DESIGN.md](DESIGN.md).

## Установка

Нужны bb 0.50 или новее, включённый плагин Working Thread (`task-queue`), macOS 13 или новее и Xcode Command Line Tools.

```
bb plugin install ~/.bb/plugins_bb/bb-plugin-touchbar --yes
~/.bb/plugins_bb/bb-plugin-touchbar/native/install.sh
```

`install.sh` собирает приложение, кладёт его в `~/Applications/BBTouchbar.app` и включает запуск при входе в систему.

## Команды

```
bb genidev-touchbar snapshot [--json]   # треды с планом: проект, счёт, осталось, время, состояние
bb genidev-touchbar endpoint [--json]   # адрес сводки для приложения
native/run.sh status|restart|stop|logs
native/uninstall.sh
```

## Проверка после правок

```
npm run typecheck && npm test && npm run build
bb plugin reload genidev-touchbar
native/build/BBTouchbar.app/Contents/MacOS/BBTouchbar --selftest
```
