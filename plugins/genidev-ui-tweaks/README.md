# Правки вида (genidev-ui-tweaks)

Набор небольших правок интерфейса bb. Каждая правка лежит в своём файле `styles/*.css`; сборка склеивает их в `dist/app.css`.
Значок закрепления, въезд правой панели поверх чата, порядок и вид кнопок шапки, крестик закрытия панели,
закрытие панели нажатием на чат или Escape (`close-on-chat.ts`), навигатор сообщений, поправки к чужим темам
(`third-party-fixes.css`: кнопка отправки с подписью, название треда в сайдбаре, правый верхний угол поля ввода без кнопки стопки Liquid Glass).

Всё держится на внутренней разметке bb (`data-*`, `aria-label`, `data-testid`), поэтому после обновления bb правка может тихо перестать работать.

## После обновления bb

1. Откройте любой тред (лучше с открытой правой панелью) и запустите `bb genidev-ui-tweaks check`.
2. Команда спрашивает открытое окно bb, находит ли оно ключевые элементы каждой правки, и печатает таблицу по-русски:
   «работает», «якорь не найден: <селектор>» или «не проверено: <причина>» (например, «панель закрыта»).
   Код выхода 1, если хоть один якорь не найден; 0, если не найден ни один.
3. «Якорь не найден» значит, что bb переименовал или убрал элемент, и эта правка не действует. Найдите новое имя в разметке
   и поправьте селектор в `styles/*.css` и в манифесте `anchors.ts`.
4. «Не проверено» не ошибка: элемент есть только в определённом состоянии. Откройте нужное (панель, навигатор сообщений, тред
   с передачей) и запустите ещё раз. Значок закрепления и подпись у кнопки отправки команда проверить не может, их смотрите глазами.
5. Посмотрите глазами: правая панель въезжает плавно, крестик на месте, порядок кнопок шапки прежний, булавка рисуется
   как значок, длинное название треда в сайдбаре обрезается многоточием и не лезет под значок статуса.

Окно отвечает только на запрос команды и один раз через несколько секунд после загрузки; наблюдателей и опросов нет.
Если окно не ответило, команда покажет снимок при загрузке (с пометкой), а без открытых окон завершится с ошибкой.

## Разработка

- `anchors.ts` — манифест правок и якорей; новую правку или новый файл стилей вносите сюда, иначе `npm test` упадёт
  (тест покрытия сверяет атрибуты в css с манифестом).
- `npm test`, `npm run typecheck`, `npm run build`, затем `bb plugin reload genidev-ui-tweaks`.

### Настройка производительности

`reduceThemeStyleWork` выключена по умолчанию. При включении BB пропускает в ChatGPT Skin и Beautiful Chat правила, которые зависят от наличия дочерних элементов. Палитра и остальные правила темы продолжают работать. Настройка применяется в окне BB и обратима через настройки плагина.

- **Hide Burn in the mobile header** (`hideBurnInMobileHeader`, off by default) hides only the Burn header action below 768px.
- **Bento New tab** (`bentoNewTab`, off by default) offers browser, terminal and GitHub tiles, or terminal and GitHub when the native browser is unavailable; `githubUser` selects a GitHub profile (empty by default), opened through the SDK browser preference; blocked URLs are not retried. Search and unsupported layouts keep the native interface.
