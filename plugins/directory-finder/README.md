# Directory в Finder

Во вкладке Info нажмите путь Directory: откроется папка среды в Finder на Mac, где живёт среда. Если среда на Linux или Windows, кнопка не появляется и остаётся штатное копирование пути.

Используются public threadInfoRow, RPC, environments.get и host entry. Server перечитывает среду, проверяет, что она ready и имеет абсолютный путь, и спрашивает у Mac, на котором живёт среда, какая у него платформа (ответ запоминается для каждой машины). Кнопка показывается только на macOS; на Linux, Windows, при ошибке запроса платформы и без пути она скрыта. Открытие идёт на том же Mac: host проверяет macOS и stat(directory), затем вызывает open -a Finder с массивом аргументов, без shell, так что пути с пробелами работают. Списка машин в коде нет.

Отключение плагина восстанавливает Copy directory. Распознавание штатного Directory зависит от DOM-разметки BB0.49 и требует проверки после обновлений.

Проверки: node --import tsx --test finder.test.ts; npx tsc --noEmit; bb plugin build .
