# Компоненты

React-компоненты плагина. Общих для других проектов среди них нет: все завязаны
на меню проекта bb и данные этого плагина.

| Компонент | Файл | Что делает |
| --- | --- | --- |
| `ProjectIcons` | `app.tsx` | Оверлей: грузит состояние по RPC, считает состояния проектов, читает настройку «Анимация иконок», отдаёт иконки боковой панели и рисует `IconMenu` в открытое меню проекта |
| `IconMenu` | `icon-menu.tsx` | Пункт «Icon» в меню проекта и боковое окно: положение у края экрана, наведение, стрелки, Escape |
| `Picker` | `picker.tsx` | Одна сетка: «Без иконки», вшитые, свои, «+»; загрузка файла, удаление с подтверждением, ошибки и состояние «Загружаю…» |
| `Cell` | `picker.tsx` | Ячейка сетки 40×40 (44×44 на телефоне), `aria-pressed` у выбранной, Delete для своих |
| `IconArt` | `picker.tsx` | Картинка в ячейке; при наведении у иконки с кадрами проигрывает цикл анимации |

Не React, но используются так же: `renderIcon` (`decoration.ts`) — стопка кадров
иконки в боковой панели, `pickerCells` (`cells.ts`) — порядок ячеек.
