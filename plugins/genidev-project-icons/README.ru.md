# Иконки проектов (bb-plugin-genidev-project-icons)

English version: `README.md`.

Плагин bb: у каждого проекта можно выбрать иконку. Она стоит слева от названия
проекта в боковой панели и оживает по состоянию проекта: агент работает, ждёт
ответа владельца, тред закончился ошибкой или успешно и ещё не открыт. Для владельца bb и агентов, которые ему помогают.

- Меню проекта (три точки) → «Icon» → окно с одной сеткой: «Без иконки», вшитые
  иконки, свои картинки, «+». Пункт стоит сразу под «Colour» (плагин «Цвета
  проектов»), а без него — над «Project settings».
- Вшитый набор: `assets/icons/icons.json`
  (`[{"id","file","name","frames"?}]`) и картинки 96×96 в WebP. Необязательное
  `frames` — кадры анимации: `{"left","right","puzzled","alert","happy"}` (глаза влево и вправо,
  озадачен, испуган, рад), файлы в той же папке; любого кадра может не быть.
  Поле `group` из старых версий игнорируется. Набор читается при каждой загрузке
  плагина: замените файлы и выполните `bb plugin reload genidev-project-icons`.
- Свои картинки: «+» в окне (вписывается в 96×96 и кодируется в WebP в браузере)
  или `bb genidev-project-icons add <файл> --name <имя>` (96×96 через `sips`,
  WebP через `cwebp`, без `cwebp` — PNG). Сохранённые раньше PNG работают.
- Личный набор (0.4.0): иконки вне плагина, чтобы не публиковать их вместе с ним.
  Папка того же формата (`icons.json` и файлы рядом); настройка «Personal icon
  pack folder» (`packDir`, абсолютный путь), пусто — `~/.bb/plugins_bb/project-icons-pack`.
  Нет папки — нет набора. Иконки идут после вшитых, вид `pack`, удалить из окна
  нельзя. Перечитывается при загрузке и командой `bb genidev-project-icons reload-pack`.
  Автоназначение не берёт `leader-*`, `star-*` и `sheikh` (список в `pack.ts`).
- Состояния (старшее закрывает младшие): ошибка — кадр `alert`, красная метка «!»,
  иконка вздрагивает; ждёт владельца — кадр `puzzled`, жёлтая метка «?»; работает —
  иконка водит глазами; готово, не просмотрено — кадр `happy`, зелёная точка; покой.
  Настройка плагина «Icon animation» выключает движение, метки остаются.
  Новому проекту плагин сам назначает свободную иконку (настройка «Give new projects an icon», включена по умолчанию); существующим проектам иконки не ставятся.
- Команды и рецепт для агентов: `skills/genidev-project-icons/SKILL.md`.
- Устройство: `ARCHITECTURE.md`; вид и тайминги: `DESIGN.md`; компоненты:
  `COMPONENTS.md`; поведение фичи: `features/project-icons.md`.

Технологии: TypeScript, React 19 (через `@get-bb/plugin-sdk/app`), SQLite плагина,
zod, тесты на `node:test` + jsdom.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `server.ts` | Хранение (SQLite плагина), настройки «Анимация иконок» и «Ставить иконку новому проекту», автоназначение новым проектам, RPC, HTTP-отдача картинок и кадров, CLI |
| `bundled.ts` | Чтение папки с `icons.json` (вшитый набор и личный) и кадров, проверка путей |
| `pack.ts` | Личный набор: папка, настройка, список иконок, которые не назначаются автоматически |
| `image.ts` | Проверка картинок по первым байтам, размеры, целостность WebP, лимиты |
| `import-file.ts` | Чтение файла для `add`: 96×96 через `sips`, WebP через `cwebp` |
| `shared.ts` | Общие для сервера и интерфейса имена: канал, кадры, настройка |
| `app.tsx` | Точка входа интерфейса: контент-скрипты, оверлей, состояния проектов |
| `project-state.ts` | Пять состояний проекта по тредам боковой панели, их приоритет и отладочный переключатель |
| `menu-watch.ts` | Находит меню проекта и держит в нём место для пункта «Icon» |
| `icon-menu.tsx` | Пункт «Icon», боковое окно, клавиатура и наведение |
| `picker.tsx` | Сетка иконок, предпросмотр анимации, добавление и удаление |
| `cells.ts` | Порядок ячеек единого списка и цикл показа по имеющимся кадрам |
| `client-image.ts` | Обработка выбранного файла в браузере (WebP, запасной PNG) |
| `decoration.ts` | Иконка с кадрами у названия проекта (подчёркивание «Цветов проектов» скрыто, если иконку поставили позже, чем выбрали цвет) |
| `scoped-observer.ts` | Наблюдатель DOM, который не просыпается на ленте чата |
| `style.css` | Сетка окна, иконка в панели, метки состояний, анимация кадров |
| `tools/icon.swift` | Обрезка сгенерированной картинки до иконки 96×96 |

## Проверка

```
npm install
npx tsc --noEmit
npm test
bb plugin build
bb plugin install . --yes && bb plugin reload genidev-project-icons
```

Тесты не читают `assets/icons`: каждый собирает свою папку с заготовками. Единственное исключение — проверка в `pack.test.ts`, что во вшитом наборе нет закрытых иконок (`leader-`, `star-`, `gg-mascot`, `sheikh`).
