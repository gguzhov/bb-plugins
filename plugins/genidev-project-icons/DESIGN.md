# Вид

Плагин не вводит своей палитры и шрифтов: пункт «Icon» и окно копируют классы
родных пунктов и меню bb, цвета берутся из переменных темы (`--foreground`,
`--muted-foreground`, `--state-hover`, `--border`, `--destructive`, `--ring`).
Своё — только сетка, размеры иконок, метки состояний и анимация.

## Размеры

| Что | Размер |
| --- | --- |
| Ячейка окна выбора | 40×40 px; на ширине до 640 px и на сенсорных экранах 44×44 px |
| Промежуток между ячейками | 2 px |
| Колонок в сетке | 6 |
| Иконка в ячейке | 32×32 px |
| Иконка в боковой панели | 16×16 px |
| Крестик удаления своей картинки | 16×16 px, на сенсорных 20×20 px |
| Кнопки подтверждения удаления | высота 28 px, на телефоне 44 px |
| Хранимая картинка | 96×96 px, WebP |

## Цвета своих элементов

Метки состояний: круг 9×9 px в правом верхнем углу иконки (торчит на 3 px за
край 16-пиксельной иконки, зазор до названия 4 px, поэтому название не
перекрывается, а ширина строки не меняется), обводка 1 px цветом фона панели
(`--sidebar`) — метка читается на тёмной и светлой теме. Размер и угол у всех
одинаковые.

| Элемент | Цвет |
| --- | --- |
| Метка «ждёт владельца», знак «?» | фон `#f5b700`, знак `#1f1a00` |
| Метка «ошибка», знак «!» | фон `#e5303f`, знак `#ffffff` |
| Метка «готово, не просмотрено», точка без знака | фон `#22a559` |
| Выбранная ячейка | рамка 2 px цветом `--foreground` |
| Ошибка в окне | `--destructive` |

## Анимация

Только CSS, кадры лежат стопкой, меняется прозрачность шагами (`steps(1, end)`).
Метки показываются всегда: при `prefers-reduced-motion` и при выключенной
настройке «Анимация иконок» остаются метки, движения нет.

| Состояние | Что видно | Тайминг |
| --- | --- | --- |
| Покой | основной кадр | без движения |
| Работает, есть кадры `left` и `right` | глаза: прямо → влево → прямо → вправо | цикл 3 с: 1,6 с / 0,5 с / 0,4 с / 0,5 с |
| Работает, кадров нет | вся иконка сдвигается на 1 px влево и вправо | тот же цикл 3 с |
| Ждёт, есть кадр `puzzled` | озадаченный кадр наклоняется −8° ↔ +8° и жёлтая метка «?» | 2 с, `ease-in-out` |
| Ждёт, кадра нет | основной кадр и жёлтая метка «?» | без движения |
| Ошибка, есть кадр `alert` | испуганный кадр, красная метка «!», короткое вздрагивание (±1 px, ±7°) | раз в 3 с, четыре рывка в последних 18 % цикла |
| Ошибка, кадра нет | основной кадр, красная метка «!», то же вздрагивание | то же |
| Готово, есть кадр `happy` | радостный кадр и зелёная точка | без движения |
| Готово, кадра нет | основной кадр и зелёная точка | без движения |
| `prefers-reduced-motion` | «работает» — основной кадр; «ждёт», «ошибка», «готово» — свой кадр (если есть) и метка, без движения | — |
| Настройка «Анимация иконок» выключена | основной кадр, у «ждёт», «ошибка», «готово» только метка | без движения |

Окно выбора: при наведении (или фокусе) иконка по кругу проигрывает все
состояния, для которых у неё есть кадры, в порядке «в работе» (глаза; нужен
`left` или `right`), «ждёт вас» (`puzzled`), «ошибка» (`alert`), «готово»
(`happy`). Каждое состояние длится 2,4 с (в «в работе» глаза: прямо 1,28 с,
влево 0,4, прямо 0,32, вправо 0,4); весь цикл — 2,4 с × число состояний.
Подпись под сеткой (высота 16 px занята всегда, окно не прыгает) меняется в такт.
Иконка без единого кадра — подпись «без анимации»; при `prefers-reduced-motion` —
основной кадр и «анимация выключена в системе».

## Иконки

- Модель генерации: GPT Image 2.6.
- Стиль: «гладкая объёмная игрушка, только голова», крупно, по центру,
  прозрачный фон, без текста — на экране иконка 16 px.
- Обрезка: `tools/icon.swift` (`icon cut <in.png> <out.png> 96` — жёсткая
  альфа, обрезка полей, квадрат, уменьшение до 96×96; `icon sheet …` — лист для просмотра).
- Перевод в WebP: `cwebp -q 92 -alpha_q 100 icon.png -o icon.webp`.
- Кадры анимации — те же голова и ракурс, меняется только взгляд (`left`,
  `right`) или выражение: `puzzled` (озадачен), `alert` (испуган: широко раскрытые
  глаза, открытый рот), `happy` (рад: глаза дугами, улыбка); файлы
  `<id>.left.webp`, `<id>.right.webp`, `<id>.puzzled.webp`, `<id>.alert.webp`,
  `<id>.happy.webp` рядом с основным. Любого кадра может не быть.
- Иконки интерфейса (пункт меню, «+») — `experimental_Icon` из SDK bb
  (`GridView`, `Plus`, `ChevronRight`).
