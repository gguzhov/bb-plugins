Иконка у каждого проекта в боковой панели bb, живая по состоянию проекта.

## Что даёт

- Пункт «Icon» в меню проекта (три точки), сразу под «Colour» от плагина «Цвета проектов» или над «Project settings».
- Одна сетка: «Без иконки», вшитые иконки, свои картинки и «+», чтобы добавить картинку PNG, JPEG или WebP с диска. Свои хранятся в лёгком WebP.
- Выбранная иконка стоит слева от названия проекта во всех открытых окнах bb.
- Пока агент работает, иконка водит глазами; пока ждёт ответа — озадачена или с жёлтой меткой «?». Настройка «Анимация иконок» выключает движение.
- Команда `bb genidev-project-icons` для агентов: список, назначение, добавление сгенерированных картинок.

## Как устроено

Выбор и свои картинки хранятся в базе плагина на сервере bb. Картинки и кадры отдаются по HTTP плагина только по id из библиотеки. Состояние проекта берётся из списка тредов боковой панели, без своих запросов.
