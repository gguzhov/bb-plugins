An icon beside every project in the BB sidebar, alive with the project's state.

## What you get

- **An Icon item in the project menu.** Open the project's three-dot menu and pick an icon from one grid: no icon, the built-in set, your own pictures, and a plus to add one.
- **Icons that react.** While an agent works in the project, the icon looks around. When a thread waits for your answer, it looks puzzled and gets a question mark. A failed thread adds an exclamation mark, a finished unread one a green dot.
- **A preview before you choose.** Hover an icon in the picker to see its states play in a loop, with a caption for each.
- **Your own pictures.** Add PNG, JPEG or WebP from the picker or with `bb genidev-project-icons add`; pictures are stored as small WebP files.
- **A personal pack.** Keep extra icons with state frames in a folder outside the plugin; they appear after the built-in set.
- **An icon for every new project.** A new project gets a free icon automatically; you can change or remove it at once.

## Good to know

- Works together with Project Underlines: a project with an icon hides its underline until you pick a colour after the icon.
- Animation follows the system "reduce motion" setting and can be turned off in the plugin settings.
- Agents can list, set, add and remove icons with the `bb genidev-project-icons` command.
