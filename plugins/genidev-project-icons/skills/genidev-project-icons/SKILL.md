# Иконки проектов

Плагин «Иконки проектов» ставит картинку слева от названия проекта в боковой
панели bb. В интерфейсе: три точки у проекта → «Icon» → одна сетка: «Без иконки»
(снимает иконку), вшитые иконки, свои картинки, «+» (добавить свою).

Библиотека = вшитые иконки плагина (`assets/icons/icons.json`) + личный набор (папка вне плагина, см. ниже) + свои картинки.
Вшитые и свои хранятся в WebP 96×96 (свои, добавленные без `cwebp`, — в PNG;
старые PNG тоже работают). Своих не больше 200. Свою картинку можно удалить; она
снимается со всех проектов.

Иконка показывает состояние проекта (старшее закрывает младшие):

1. ошибка — тред закончил ход ошибкой и владелец его не открыл: красная метка «!»,
   кадр `alert`, иконка вздрагивает;
2. ждёт владельца (вопрос, разрешение, план) — жёлтая метка «?», кадр `puzzled`;
3. работает — водит глазами (или чуть качается, если кадров нет);
4. готово, не просмотрено — тред закончил ход успешно, владелец не открыл:
   зелёная точка, кадр `happy`;
5. покой.

Если нужного кадра нет, показывается основной. Выключить движение:
`bb plugin config genidev-project-icons set animation false` (метки остаются).

## Команды

| Команда | Что делает |
| --- | --- |
| `bb genidev-project-icons list [--json]` | Проекты и их иконки (`iconId` или «без иконки»); автоматически назначенные помечены «авто» (в JSON `auto: true`), пока владелец не выберет другую. Новому проекту плагин сам ставит свободную иконку (не `leader-*`, `star-*` и не `sheikh`); снятая владельцем иконка автоматически не возвращается; отключается настройкой «Ставить иконку новому проекту» |
| `bb genidev-project-icons icons [--json]` | Библиотека: `id`, `kind` (`builtin`/`pack`/`custom`), название, `frames` (какие кадры есть) |
| `bb genidev-project-icons set <projectId> <iconId\|none>` | Назначить иконку проекту или снять (`none`) |
| `bb genidev-project-icons reload-pack [--json]` | Перечитать личный набор; пишет, сколько иконок прочитано и сколько пропущено, с причинами |
| `bb genidev-project-icons add <файл> --name <название> [--json]` | Добавить свою картинку с диска этой машины |
| `bb genidev-project-icons remove <iconId> [--json]` | Удалить свою картинку (`custom-…`) |

`add`: файл PNG, JPEG или WebP (проверяется по содержимому, не по имени), SVG не
принимается. Относительный путь считается от текущей папки. На macOS картинка
вписывается в прозрачный квадрат 96×96 и сохраняется в WebP, если установлен
`cwebp` (`brew install webp`), иначе в PNG; итог не больше 512 КБ и 512 px.
Название до 60 символов. Ответ `--json`: `{"id","name","kind"}`.

## Рецепт: сгенерировать иконку и добавить

1. Сгенерируйте квадратную картинку с прозрачным фоном тем инструментом
   генерации картинок, который у вас есть. Простой предмет или голова персонажа
   по центру, без текста, крупно: на экране она будет 16 px.
2. Добавьте исходник как есть, плагин сам приведёт его к 96×96 WebP:
   `bb genidev-project-icons add source.png --name "Ракета" --json`
   и запомните `id` из ответа.
3. Если иконка нужна конкретному проекту: найдите его id через
   `bb genidev-project-icons list`, затем
   `bb genidev-project-icons set <projectId> <id>`.

Все открытые окна bb обновляются сразу. Временные файлы картинок после добавления
можно удалить: плагин хранит свою копию.

## Личный набор

Иконки, которые нельзя публиковать вместе с плагином (шаржи и т. п.), лежат в
своей папке: по умолчанию `~/.bb/plugins_bb/project-icons-pack`, другая — настройка
плагина «Personal icon pack folder» (`packDir`, только абсолютный путь):
`bb plugin config genidev-project-icons set packDir /абсолютный/путь`. Формат как у
`assets/icons/`: `icons.json` (`id`, `file`, `name`, `frames`?) и файлы рядом; читаются
только названные в `icons.json` файлы внутри папки (без `..`, ссылки наружу не
работают). Иконки идут после вшитых, `kind: pack`, из окна выбора не удаляются, кадры
работают как у вшитых. Совпал id со вшитой — побеждает вшитая. После правки папки:
`bb genidev-project-icons reload-pack`. Не кладите в `assets/icons/` иконки с id
`leader-*`, `star-*`, `gg-mascot`, `sheikh`: тест `pack.test.ts` это не пропустит.

## Кадры анимации вшитых иконок

Кадры есть у вшитых иконок и иконок личного набора. В `icons.json` (там же, в личном наборе) у записи —
необязательное `"frames": {"left": "<id>.left.webp", "right": "<id>.right.webp", "puzzled": "<id>.puzzled.webp", "alert": "<id>.alert.webp", "happy": "<id>.happy.webp"}`
(глаза влево, глаза вправо, озадачен, испуган — широко раскрытые глаза и открытый рот,
рад — глаза дугами и улыбка), файлы рядом с основным, 96×96 WebP, тот же персонаж и ракурс. Любого кадра может
не быть. После правки: `bb plugin reload genidev-project-icons`; битые кадры
пропускаются с записью в `bb plugin logs genidev-project-icons`.
