# Working Thread (plugin id `task-queue`)

Плагин для bb. Рабочий тред: план работы ведущего агента с очередями и
тикетами, кто что делает и сколько осталось, в одной карточке над полем
ввода. Для ведущего агента и владельца, который следит за его работой. В
списке плагинов bb он называется «Working Thread»; id, папка, команда
`bb task-queue` и инструмент `task_queue_plan` прежние.

## Что делает

- Карточка видна, пока в треде есть незавершённый план; завершённый остаётся
  30 секунд. Фоновые агенты и команды треда плагин читает сам, из ленты
  треда (`activity-source.ts`), и показывает внутри карточки. Других
  плагинов для этого не нужно.
- Пока карточка на месте, собственная плашка bb «Active child threads» над полем
  ввода скрыта: дочерние треды видны под своими тикетами. Если дочерний тред
  ждёт ответа (строка вопроса в плашке), плашка остаётся. Выключите плагин —
  плашка bb вернётся.
- Шапка в одну строку: точка состояния, «план · текущий тикет» (если в работе
  несколько — «3 тикета в работе»; кодов тикетов в шапке нет) и не больше
  трёх плашек: «2 / 18», приёмка «92%», время «21 мин».
- Раскрытая: строка плана (слово состояния, счётчик, время), под ней не
  больше двух плашек — «~19 мин» (сколько осталось по темпу принятых
  тикетов) и «приёмка 92%»; без данных строки нет. Полоска делений по
  тикетам. Очереди со счётчиком «3 / 5», готовая свёрнута в «✓ 5 / 5».
- Строка тикета: значок статуса, плашка исполнителя целиком (без исполнителя
  - код), название, справа не больше двух плашек: слово статуса (по-русски
  «в очереди», «в работе», «ждёт», «доработка», «приёмка», «готов»,
  «ошибка», «отменён»; по-английски `queued`, `running`, `waiting`, `rework`,
  `review`, `done`, `failed`, `cancelled`), затем приёмка `5/6` или возвраты `↺2`. Баллов на экране нет: они только
  в расчётах.
- У тикета в работе, к которому привязан агент или фоновая команда, справа
  значок раскрытия: по нажатию видно, что агент делает сейчас (команда,
  строка запуска и последние строки вывода, иначе «Думает или пишет: команда
  сейчас не выполняется»), и «12 мин · 959k токенов». Агент или команда
  привязывается полем `agent` тикета (описание, с которым их запустили:
  `start:[{ticket,agent}]` или `assign`); агент — ещё и по коду тикета в
  начале своего названия («UX · Крестик»), а если в работе ровно один тикет
  и работает ровно один агент — к этому тикету. У тикета в работе плашка
  «Неон · 12 мин». Остальное фоновое — внизу раскрытой карточки, в группе
  «Ещё в фоне · N» (строка на агента или команду, раскрывается так же), и
  в подсказке состояния плана («Ещё работают без тикета: …»).
- Подсказка при наведении (с клавиатуры — при фокусе, на телефоне —
  нажатием с удержанием) в стиле bb: описание тикета (`desc`)
  или его название; состояние со временем («В очереди 12 мин», «В работе
  8 мин · до этого ждал в очереди 4 мин · делает Opus 5.5», «Сдан на приёмку
  3 мин назад · работа заняла 15 мин», «Принят · работа заняла 21 мин ·
  подтверждено 5 из 6 критериев»); «Сейчас: думает», если на тикете агент.
  Подсказки есть и у очередей, плашек строки плана и полоски.
- «Волна» в начале названия показывается как «Очередь». Старые тикеты, у
  которых всё записано в названии («RH участок, 3 б., Sonnet 5.5»),
  разбираются при показе.
- Учитывает «колоду» Liquid Glass.
- Язык: настройка `language` — `auto` (по умолчанию), `en`, `ru`. `auto` —
  русский, если язык страницы или браузера начинается с `ru`, иначе
  английский; для сообщений команды — язык системы. Все фразы в одном
  словаре `i18n.ts`. Названия планов, очередей и тикетов показываются как
  их написал агент. Строки ответа команды и инструмента для агента
  (`v5: 2/6, running, active: …`) — постоянный формат на английском.

## Команда и инструмент

Одна операция JSON за вызов. Полный контракт - в `skills/task-queue/SKILL.md`.

```sh
bb task-queue plan '{"id":"v5","title":"Экраны v5","epics":[{"name":"Очередь 1: экраны","tickets":[{"title":"Карточка пациента","code":"CS","points":3,"owner":"Sonnet 5.5","criteria":6,"desc":"Карточка пациента с вкладками визитов и оплат."}]}]}'
bb task-queue plan '{"id":"v5","start":["CS"]}'
bb task-queue plan '{"id":"v5","review":["CS"]}'
bb task-queue plan '{"id":"v5","accept":[{"ticket":"CS","confirmed":5,"total":6}]}'
bb task-queue plan '{"id":"v5","describe":[{"ticket":"CS","desc":"Новое описание."}]}'
bb task-queue plan show [--json] [--full]   # --full: описания тикетов
bb task-queue plan clear [--id v5]
bb task-queue migrate [--again]     # необязательно: перенос планов старой версии
```

Агентский инструмент `task_queue_plan` принимает тот же JSON.

## Хранение

Планы хранятся в kv плагина (`plan:<threadId>`), до 10 на тред.

## Совместимость со старым плагином (необязательно)

До версии 0.5 план хранил другой плагин того же автора, `background-peek`.
Если он установлен, он продолжает работать как раньше: его старое имя
команды и инструмента (`bb background-peek plan …`, `background_peek_plan`)
пересылает вызов сюда по RPC `cli` и `tool`, а его карточка прячется, пока
здесь виден план (он спрашивает RPC `plan`). Его сохранённые планы
переносятся сюда один раз (RPC `exportPlans`, отметка `migration:v1`,
`bb task-queue migrate` печатает сверку). Без него всё это просто не
вызывается: карточке, агентам и команде он не нужен.

## Устройство

| Файл | Роль |
|---|---|
| `plan.ts` | Модель плана и операции, выбор плана для карточки, ответ и текст `plan show`. Покрыт тестами |
| `metrics.ts` | Показатели плана и эпика по отметкам времени. Покрыт тестами |
| `i18n.ts` | Словарь всех фраз на английском и русском, выбор языка по настройке, время и имена агентов на двух языках. Покрыт тестами |
| `activity.ts` | Чистый разбор ленты треда: какие фоновые агенты и команды работают и что делают. Покрыт тестами |
| `activity-source.ts` | Чтение ленты треда для карточки: кэш 1,5 с, строка запуска команды, последние строки вывода из файла задачи (только из временной папки провайдера). Покрыт тестами |
| `hint.ts` | Подсказки и строки про агентов на языке карточки: время по статусу, привязка агента или команды к тикету (поле agent, код, один на один). Покрыт тестами |
| `format.ts` | Код тикета, «Очередь» вместо «Волна», плашка исполнителя, разбор старых названий, время. Покрыт тестами |
| `plan-service.ts` | Хранение по тредам (одна запись за раз), команда `bb task-queue`, ответ инструмента |
| `migrate.ts` | Слияние старых планов и сверка переноса. Покрыт тестами |
| `server.ts` | Настройка языка, RPC `plan` для карточки, `activity` (фоновые агенты и команды из ленты треда), `cli` и `tool` для старого имени (принимает только от `background-peek`), команда, инструмент, необязательный перенос |
| `app.tsx`, `app.css` | Баннер композера: карточка плана на переменных темы bb, подсказки на `components/ui/tooltip.tsx` из реестра bb |

## Разработка

```sh
npm run typecheck
npm test
bb plugin build
bb plugin install . --yes   # первый раз
bb plugin reload task-queue
```

Технологии: TypeScript, React (из bb), `@get-bb/plugin-sdk`, zod. Тесты на
`node --test` прямо из `.ts` (Node 22.6+).
